# 🔎 Wikipedia Search Application

A simple and responsive web application that allows users to search for information using the **Wikipedia REST API**. The application fetches search results dynamically and displays relevant information based on the user's query.

## 🚀 Features

* Search for information using keywords
* Fetch data using REST API calls
* Display search results dynamically
* Handle user input through JavaScript
* Responsive and simple user interface
* Fast and interactive search experience

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and layout
* **JavaScript** – Application logic and DOM manipulation
* **REST API** – Fetching Wikipedia search results

## 🔄 How It Works

1. User enters a search query.
2. JavaScript sends a request to the Wikipedia API.
3. The API returns relevant search results.
4. The application processes the response.
5. Results are dynamically displayed on the webpage.

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/wikipedia-search-application.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional installation or server setup is required.
